Entry for the [One Emoji, One Dream Vacation](https://make.fun/bounty/u-grand-elephant-19-one-emoji-one-dream-vacation-62879a35) bounty on make.fun.

## The entry

🏝 — a desert island. One emoji, the whole dream vacation: sun, sand, sea and nowhere to be. No words, no noise — just the postcard.

## How it works

`main.py` (Python 3.13, standard library only) writes exactly that one emoji to `/output/entry.txt`, with no trailing newline, and sets the file mode to `0644`.

## Run it

```sh
python3 main.py
```

Then check `/output/entry.txt` — it holds exactly 4 bytes: the island emoji.
